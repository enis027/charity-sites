# Languages, scripts and formatting

## Interface strings

`template/i18n/en.json` is the master list (105 keys). Shipped and reviewed: `en`, `tr`. Shipped, needs native review: `ar`. For any other language, translate `en.json` into `site/i18n/<lang>.json`:
- keep every key and `{placeholder}`;
- use the organisation's own words where it has them (its label for "Donate", "Member", "Contact");
- error messages follow the GOV.UK pattern in that language: say what to do ("Enter your email address"), no blame, no "please/sorry/invalid";
- add `months` (12 names) and set `_meta.dir` (`rtl` for Arabic, Hebrew, Persian, Urdu…).

Contributions of reviewed language files are welcome (see CONTRIBUTING.md).

## Fonts (chosen automatically from `lang`)

| Languages | Heading / Body |
|---|---|
| Latin, Cyrillic, Greek, Vietnamese (en, tr, de, fr, es, pt, it, pl, ru, uk, el, vi, az, ro…) | Source Serif 4 / Source Sans 3 |
| Arabic, Persian | Noto Naskh Arabic / Noto Sans Arabic |
| Urdu | Noto Nastaliq Urdu / Noto Sans Arabic |
| Hebrew | Noto Serif Hebrew / Noto Sans Hebrew |
| Hindi, Marathi, Nepali | Noto Serif / Sans Devanagari |
| Bengali, Tamil, Telugu, Thai, Khmer, Georgian, Armenian, Amharic | matching Noto Serif / Noto Sans families |
| Japanese, Chinese (Simplified), Korean | Noto Serif / Sans JP, SC, KR |

Override with `fonts.heading` / `fonts.body` only for a font the organisation already uses and that covers its script (check Turkish ı İ ş ğ, Vietnamese stacked diacritics, Arabic ligatures in the screenshots).

**Privacy (EU/UK):** fonts load from Google Fonts by default. Some EU data-protection authorities and courts consider this an IP-address transfer that needs consent. For EU/UK organisations, self-host: download the WOFF2 files and write `site/fonts/fonts.css` with the `@font-face` rules, then set `"fonts": {"self_hosted": true}`. The build copies the folder and links `fonts/fonts.css` instead of Google Fonts. Mention this in the README.

## Right-to-left

Set by language automatically (`dir="rtl"`). The stylesheet uses logical properties only, so no RTL overrides are needed. Directional arrows flip; numbers, IBANs, phone numbers and emails are isolated as LTR. Check in the screenshots: breadcrumbs, amount chips, footer columns and the sticky bar.

## Numbers, currency, dates

- `currency_display`: `symbol`, `position` (`before`/`after`), `thousands` separator. Use what the organisation writes (e.g. Turkish "100 ₺" → `after`, "." thousands; UK "£25" → `before`, ",").
- Dates in `site.json` are ISO; they render with the month names from the i18n file, day-month-year order except `en-US`.
- Phone numbers keep the organisation's formatting; `tel:` links strip spaces.
